# Support

Use the appropriate GitHub channel so questions are easy to find and answer:

- Open a **bug report** when a solution produces incorrect output or fails to compile.
- Open a **solution proposal** when suggesting a new problem or algorithm.
- Start a GitHub Discussion for usage questions or general ideas, if Discussions are enabled.

When asking for help, include the source file, compiler and version, input, expected output, actual output, and any error messages. Do not use public issues to report security concerns; follow [SECURITY.md](SECURITY.md) instead.
