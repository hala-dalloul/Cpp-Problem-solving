# Security Policy

## Supported versions

This educational repository does not publish versioned releases. Security fixes are applied to the latest revision of the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature on the repository's **Security** tab. If that feature is unavailable, contact the maintainer privately through the contact method on their GitHub profile.

Include a clear description, reproduction steps, affected files, possible impact, and any suggested fix. You should receive an acknowledgement within seven days. Please allow reasonable time for investigation before disclosing the issue publicly.
