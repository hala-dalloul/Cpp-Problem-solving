# C++ Problem Solving

A collection of C++ solutions and exercises focused on problem solving, algorithms, and competitive programming fundamentals.

## Overview

This repository documents an active transition toward C++ for programming contests and algorithmic problem solving.

It contains independent solutions covering searching, sorting, strings, arrays, simulation, and other foundational problem-solving techniques.

## Topics Covered

- Binary Search
- Sorting and Bubble Sort
- Arrays and sequences
- Strings and character processing
- Frequency and uniqueness problems
- Neighbor and grid problems
- Maximum subsequence problems
- Search-based problems
- Encryption and decryption exercises
- Mathematical and simulation problems
- Standard input/output

## Repository Structure

Solutions are organized as standalone C++ source files.

```text
Cpp-Problem-solving/
├── *.cpp
└── *.exe
```

The source files are the primary learning material. Compiled executables are generated artifacts and are not required to understand the solutions.

## Running a Solution

Compile an individual source file:

```bash
g++ "Binary Search.cpp" -o binary_search
```

Run it:

```bash
./binary_search
```

On Windows:

```powershell
.\binary_search.exe
```

The exact input format depends on the selected problem and can be read from its source code.

## Problem-Solving Approach

The repository is used to practice a repeatable process:

1. Understand the problem and constraints.
2. Identify edge cases.
3. Select an appropriate algorithm.
4. Implement the solution in C++.
5. Test representative inputs.
6. Review time and space complexity.
7. Refactor when a clearer or more efficient approach is found.
