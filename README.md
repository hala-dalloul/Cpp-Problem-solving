# C++ Problem Solving

A collection of C++ solutions and exercises focused on problem solving, algorithms, and competitive programming fundamentals.

## Topics

- Binary search
- Sorting
- Arrays and strings
- Frequency counting
- Prefix techniques
- Two-pointer techniques
- Subsequences and subarrays
- Grid and neighbor processing
- Mathematical problems
- Simulation
- Encryption and decryption

## Structure

The repository contains independent .cpp source files. Compiled executables are intentionally not tracked.

## Running a Solution

```bash
g++ "Solution.cpp" -std=c++17 -O2 -o solution
./solution
```

On Windows:

```powershell
g++ "Solution.cpp" -std=c++17 -O2 -o solution.exe
.\solution.exe
```

## Problem-Solving Workflow

1. Understand the input and output.
2. Identify constraints and edge cases.
3. Select an algorithm or data structure.
4. Implement and test the solution.
5. Review time and space complexity.
6. Refactor when a clearer or more efficient approach is found.

## Repository Hygiene

The repository ignores generated .exe, .out, .obj, .o files, build directories, and common IDE metadata through .gitignore.

## Development Direction

The current focus is strengthening C++ fluency for competitive programming, especially STL containers and algorithms, complexity analysis, searching, sorting, strings, arrays, and reusable problem-solving patterns.

## Contributing

Add clear, self-contained solutions and keep generated binaries out of source control.
